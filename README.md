ComfyUI-ShiroTools is a collection of small utility nodes for ComfyUI.

This package was created as a general toolbox for solving practical workflow issues: things like adding delays, passing data through with timing control, cleaning video loop boundaries, reducing loop stutter, and testing seamless loop transition helpers.

It does not have one strict focus. Instead, it groups together small nodes that are useful for different situations and workflow fixes.
